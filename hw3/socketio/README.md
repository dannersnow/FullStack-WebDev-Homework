Socket.IO Chat App

Description:
This program follows the Socket.IO chat tutorial. You can send messages and see messages from other users connected to the server.
https://socket.io/get-started/chat

How to Run:

1. Run npm install
2. Run node index.js
3. Open http://localhost:3000 in your browser
4. Open a second window and open the same as above, you should be able to see those messages in the original window as well!
